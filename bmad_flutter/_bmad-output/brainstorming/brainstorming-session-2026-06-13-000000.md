**[Exploration #1]: 자기 성장형 앱**
_Concept_: 앱이 빈 껍데기로 시작, 스테이지 클리어마다 실제 기능 추가. 학습 진행 = 앱 성장.
_Novelty_: 학습 결과물이 곧 앱 자체.

**[Exploration #2]: UI 물리학 실험실**
_Concept_: 스테이지마다 레이아웃 원리를 인터랙티브 놀이터에서 실험. 슬라이더/드래그로 속성 실시간 조작.
_Novelty_: 손으로 만지면서 체득하는 학습.

**[Exploration #3]: 발현(Manifestation) 시스템**

_Novelty_: "내가 배운 만큼 앱이 예뻐진다"는 보상 체계.
