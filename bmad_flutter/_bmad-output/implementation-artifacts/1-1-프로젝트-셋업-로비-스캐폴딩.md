### iOS 실기기 빌드 절차 (README에 문서화할 내용)
[Source: architecture.md#Infrastructure & Deployment, NFR1/NFR5, AR5]
1. iPhone을 Mac에 USB 연결, 기기 신뢰.
2. `flutter devices`로 실기기 인식 확인.
3. `open ios/Runner.xcworkspace`로 Xcode 열기 → Signing & Capabilities에서 무료 Apple 계정(Personal Team) 선택, 고유 Bundle ID 설정 (`com.sy.bmadFlutter`).
4. `flutter run -d <device-id>` 또는 Xcode에서 직접 Run.
5. 기기에서 설정 → 일반 → VPN 및 기기 관리 → 개발자 앱 신뢰.
6. **제약(AR5):** 무료 Apple 계정은 7일 후 앱 만료 → 재빌드/재설치 필요. App Store 미사용(NFR1).
